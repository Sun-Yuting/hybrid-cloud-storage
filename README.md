## Project Overview

このプロジェクトは、ミッションクリティカルな業務に最適なインフラアーキテクチャを提案します。<br>
データとストレージに焦点を当てて、以下の要件を目標としています。<br>
- 100%に近いデータの可用性の保証
- マイクロ秒級の復旧時間
- ハイブリッドクラウドならではのいいとこどり：
  + オンプレミス環境で性能を保証
  + クラウド環境ならではの俊敏性と災害対策を実現

<br>

This project is to design an infra architecture which meets the most demanding SLAs for financial-grade and mission-critical workloads.<br>
Also this project mainly focus on data & storage.<br>
- Near 100% Data Availability
- Micro-second Level Recovery Time
- Hybrid Cloud Synergy
  + On-Premise for Performance
  + Cloud for Agility & DR
